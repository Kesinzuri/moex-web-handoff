# moex-web

Веб-терминал MOEX Forex в одном Python-файле: котировки и ставки фондирования,
баланс и позиции ЛК lite-invest, позиции cTrader, журнал сделок с PnL,
уведомления в Telegram и мини-приложение для Windows (Electron).

## Требования

- Python 3.9+ (проверено на 3.13). Сторонних пакетов не нужны — только
  стандартная библиотека.
- `curl` в PATH — используется для запросов к API биржи.
- Часовой пояс Europe/Moscow должен быть доступен в системе. На Windows, если
  системных tzdata нет: `pip install tzdata`.
- Node.js и npm — только для мини-приложения (`win-app/`).

## Быстрый старт

```bash
cp config.example.json config.json   # при необходимости отредактировать
python3 app.py
```

Открыть в браузере: http://localhost:8642

Без `config.json` приложение тоже запускается — все источники покажут
состояние «не настроено».

## Конфигурация (config.json)

Все секции необязательны, заполнять только нужные.

| Секция | Поля | Назначение |
|---|---|---|
| `server` | `host`, `port`, `allowed_clients` | Интерфейс/порт (по умолчанию `0.0.0.0:8642`) и список IP, которым разрешён доступ (по умолчанию только `127.0.0.1` и `::1`). `["*"]` — разрешить всем. |
| `lite_invest` | `login`, `password` | Аккаунты ЛК lite-invest (массив — несколько аккаунтов). |
| `ctrader` | `label`, `client_id`, `client_secret`, `access_token`, `refresh_token`, `host` (`live`/`demo`) | Аккаунты cTrader (массив). |
| `tradersdiaries` | `token`, `device_id` | Доступ к дневнику трейдера. |
| `telegram` | `token`, `chat_id` | Бот для уведомлений. |

Пример заполненного файла — `config.example.json`.

## Что умеет интерфейс

- **Сделки** — журнал сделок: создание, закрытие, редактирование, привязка
  позиций MOEX и cTrader/Forex, расчёт комиссии, точка входа/выхода, PnL
  (включая конвертацию форекс-результата в рубли по курсу USD).
- **MOEX** — вкладка появляется, если заданы аккаунты lite-invest: баланс,
  финансовый результат, максимальные потери, позиции по счетам.
- **Diary** — вкладка появляется, если настроен tradersdiaries.
- **cTrader** — вкладка появляется, если заданы аккаунты cTrader: позиции,
  текущие цены, PnL в рублях.
- **Фандинг** — ставки фондирования и цены инструментов (срочный рынок
  Московской биржи).

Данные обновляются фоновыми потоками — интерфейс не блокируется на сетевых
запросах, при старте подхватываются кэши из файлов.

## Файлы данных

В процессе работы рядом с `app.py` создаются файлы (можно удалить — будут
пересозданы; содержат персональные данные и в git не попадают):

- `deals.json` — сделки и привязки позиций;
- `balance_history.json` — история баланса;
- `td_cookies.txt` — куки сессии tradersdiaries;
- `.ct_cache.json`, `.lk_cache.json`, `.fund_cache.json`, `.usd_cache.json` —
  кэши источников, ускоряют старт и переживают перезапуск;
- `app.log` — лог запуска.

## Мини-приложение (win-app)

Компактное окно поверх других окон, которое открывает тот же веб-интерфейс
(вкладка «Сделки» скрыта). По умолчанию подключается к
`http://127.0.0.1:8642`, адрес можно переопределить переменной окружения
`MOEX_URL`.

```bash
cd win-app
npm install
npm start            # запуск в режиме разработки
npm run dist         # сборка zip для Windows (на Windows)
```

Собранный архив раздаётся самим приложением по адресу
`/download/win-app`.

## HTTP API

- `GET /` — веб-интерфейс;
- `GET /api/funding` — цены и фандинг;
- `GET /api/lk`, `GET /api/lk/refresh` — данные lite-invest;
- `GET /api/td`, `GET /api/td/refresh` — данные дневника;
- `GET /api/ct`, `GET /api/ct/refresh` — данные cTrader;
- `GET /api/deals`, `POST /api/deals/save|update|delete|create|close|bind|unbind|commission` —
  операции со сделками;
- `GET /download/win-app` — архив мини-приложения.

## Безопасность

- Веб-интерфейс доступен только с адресов из `server.allowed_clients`
  (по умолчанию — только localhost).
- `config.json` содержит пароли и токены и исключён из git через `.gitignore`;
  правки конфигурации делаются в файле, в шаблоне `config.example.json`
  секретов нет.
